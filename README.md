# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

## 配伍禁忌

炮制员在顶栏「配伍禁忌」页维护禁忌对：甲味与乙味不得在同一自然日（北京时间）都成功写入。本日已有甲的放行或未放行行，再写乙即拒写并点名冲突味。禁忌对可增删，增删均记入履历；质检员能看禁忌表与履历，不能增删。落地专页含当日冲突提示、禁忌对维护、增删履历三区，写入失败提示只作引导，不代替专页。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 顶栏进入「配伍禁忌」，登记甘草 × 黄芩禁忌对；先写一条甘草（成功），再写黄芩被拒写，提示点名甘草。
5. 删掉该禁忌对后，再写黄芩成功；增删均记入履历。
6. checker 能看禁忌表与履历，但看不到登记、删除按钮。

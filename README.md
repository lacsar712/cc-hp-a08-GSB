# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

配伍禁忌表挡写入：炮制员维护禁忌对，同一自然日（按 UTC+8 计）内禁忌两味不得都成功写入——若本日已有甲味的记录（无论放行与否），再写乙味即拒写并在报错中点名冲突味。禁忌对可增删，增删均记入履历；质检员只能查看禁忌表与履历，不能增删。顶栏「配伍禁忌」进入专页，含禁忌对维护、当日冲突提示、增删履历。样例数据记为前一日，不参与当日判定。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. processor 在「配伍禁忌」页登记甘草×黄芩禁忌对；当日写甘草成功，再写黄芩被拒且报错点名甘草。
5. 删除该禁忌对后，再写黄芩成功；增删均出现在履历中。
6. checker 能看禁忌表与履历，但无增删入口（接口亦返回 403）。
